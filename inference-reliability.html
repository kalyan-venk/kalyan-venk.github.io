Graduate Research

Experimental Design & LLM Evaluation

Studying when automated feedback improves generated code, when it makes results worse and how to tell the difference with reliable measurements.

  • Designed 10 experimental phases to compare baseline and monitored model performance across model capabilities, settings and code benchmarks.
  • Analyzed 17,000 model-evaluation records using paired comparisons and 95% confidence intervals to quantify changes in generated-code performance.
  • Built a Python evaluation workflow with LangGraph and MLflow, combining code checks, experiment tracking and failure analysis. Tested 5 local model families across 3 code benchmarks.

My first-author Master's research manuscript with 2 DePaul faculty co-authors is under conference review.

The paper, code and detailed observations are anonymized and remain private to follow the conference's double-blind review standards. The conference name is intentionally withheld.
